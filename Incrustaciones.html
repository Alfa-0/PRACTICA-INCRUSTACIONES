AUDIO DESDE UNA URL CON AUTOPLAY Y LOOP

EL AUTOPLAY HACE QUE EL AUDIO SE REPRODUZCA AUTOMATICAMENTE AL CARGAR LA PAGINA, Y EL LOOP HACE QUE EL AUDIO SE REPITA INFINITAMENTE, DADO DE QUE SIN CONTROLS NO APARECE PARA PAUSAR EL AUDIO, SE PUEDE USAR EL CONTROLS PARA QUE APAREZCA EL BOTON DE PAUSA Y REPRODUCIR, PERO SI SE QUIERE QUE NO APAREZCA EL BOTON DE PAUSA Y REPRODUCIR, SE PUEDE USAR EL AUTOPLAY Y LOOP SIN CONTROLS, PERO ENTONCES NO SE PODRA PAUSAR EL AUDIO. POR ESO SE RECOMIENDA USAR EL AUTOPLAY Y LOOP CON CONTROLS, PARA QUE EL USUARIO PUEDA PAUSAR EL AUDIO SI LO DESEA.
